Each upcoming event is should be a large, clearly separated card.

The event title and date come first, before the poster, so visitors immediately know what they're looking at.

Important information is separated into clearly labelled sections, when relevant:
- When
- Where
- Booking
- Parking
- Contact
- Programme

Event posters remain prominent without overwhelming the text.

Important actions such as “View map & parking information” should be large, obvious buttons.

The page needs to be mobile-friendly and adaptable to smaller screens.

Past events are kept separate and presented more compactly, since they don't need as much detail.

No complicated interactions — the essential information is visible without visitors having to click around.
