WHDFCP WEBSITE — MAINTENANCE NOTES

This version of the site is a simple static website designed for Cloudflare Pages.

FILES
- index.html       Home page
- events.html      Events page
- partners.html    Partner directory
- styles.css       Shared styling
- images/          Photographs, the WHDFCP logo and generic partner icons

LOGO
The main WHDFCP branding uses images/WHDFCP_Logo_Large.png. Keep this file in place.

PARTNER ICONS
Partner cards use simple locally stored generic icons in images/partner-icons/ rather than third-party logos.

UPDATING THE SITE
1. Keep a backup copy of the whole website folder before making changes.
2. Edit the relevant HTML or CSS file.
3. Preview the pages locally if possible.
4. Upload/deploy the updated files to Cloudflare Pages.
5. Check the home page, events page and partners page on desktop and mobile.

DOMAIN AND HOSTING
The organisation should control its Cloudflare account and .org.uk domain. Avoid making a volunteer's personal account the sole point of access.

ACCESSIBILITY
Keep the skip link, keyboard focus styles, meaningful image alt text, readable text sizes and responsive layout when editing the site.
